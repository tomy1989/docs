## 2026-09-01 — Documentation expansion & API reference

### Added

- **Conversations API** — read the inbox as threads: list conversations, page through a thread, track unread counts, assign a thread to an agent or team, snooze or close it, and send a typing indicator. See the [Conversations guide](/chats/conversations).
- **Retry failed messages** — smart retry candidates with deduplication and exclusion counts, bulk retry up to 500 messages, and task polling. See [Retry Failed Messages](/messages/retries).
- **Contact export** — export a filtered contact list as CSV or XLSX, with a background job and a 24-hour download token for large exports. See [Export Contacts](/contacts/export).
- **Template analytics** — Meta's delivery, read and click metrics per template, plus a top-templates ranking. See [Template Analytics](/templates/analytics).
- **Conversation analytics** — conversation counts and costs by direction and category, daily trends, and MM Lite savings estimates. See [Conversation Analytics](/analytics/conversations).
- **Ice breakers, commands and welcome message** — configure what WhatsApp shows before a customer types. See [Ice Breakers & Commands](/instances/conversational-automation).
- **WhatsApp QR codes** — create scannable codes and click-to-chat links with a pre-filled message. See [WhatsApp QR Codes](/instances/qr-codes).
- **Appointments API** — list, create, reschedule and cancel bookings across Google Calendar and Calendly. See the [Appointments API](/calendar/appointments).
- **Shopify product browsing and draft orders** — search the connected store, read variants, and turn a chat into a payable checkout link. See the [Shopify integration](/integrations/shopify).
- **Interactive API reference** — every documented endpoint now has a generated reference page with schemas and a request playground, authenticated with `X-MEGASEND-AUTH`.

### Changed

- Documentation navigation is split into **Guides** and **API Reference** tabs, with guides grouped by topic.

### Fixed

- Corrected the `POST /messages/send` example on the [Authentication](/authentication) page, which used Meta's `to` and `type` fields instead of MegaSend's `instance_id`, `recipient` and `message_type`.
- `POST /contacts/` and `GET /contacts/` are documented with their trailing slash, matching the API.

## 2026-08-02 — Calendar integrations & AI appointment booking

### Added

- **Calendly integration** — connect a Calendly account via OAuth (`GET /calendly/auth/start`), then list event types and scheduling links, check connection status, refresh webhooks, and disconnect. See the [Calendly guide](/calendar/calendly).
- **Google Calendar integration** — connect Google Calendar via OAuth, list calendars, and query availability. See the [Google Calendar guide](/calendar/google-calendar).
- **AI appointment booking** — once a Calendly account is connected, the AI assistant can offer event types and send single-use scheduling links directly inside chat conversations. Configured through AI settings (`appointment_booking_enabled`). See the [AI booking guide](/calendar/ai-booking).

## 2026-07-13 — v2.0.0

**Current stable release.**

### Added

- **Multi-channel messaging** — single API surface covers WhatsApp (Cloud API), Instagram Direct, Facebook Messenger, Telegram, TikTok (Login Kit), and Telnyx SMS/voice channels. Each channel is identified by a `platform` field on the instance.
- **WhatsApp Groups** — create and manage WhatsApp groups, send group messages, and receive group webhooks.
- **Instagram Marketing Messages** — token-based opt-in marketing broadcasts with Custom Fields and Segments (ManyChat-parity).
- **Website Widget** — embeddable channel launcher with live-chat session tokens (Phase 1 shipped; Phase 2 in progress).
- **Media Library** — upload once, reuse across messages, templates, and campaigns. Tracks Meta expiry (30-day window), usage counts, and supports bulk delete.
- **Campaigns** — schedule and send bulk message campaigns with rate-limiting, audience segments, and per-recipient status tracking.
- **Unsubscribe Management** — generate per-contact opt-out codes, process unsubscribes via public URL (no auth required), and block/unblock contacts programmatically.
- **Analytics** — instance-level and campaign-level delivery, read-rate, and conversion metrics.
- **Automation Flows** — keyword triggers, flow builder, and per-channel automation rules (WhatsApp, Instagram, Messenger).
- **Contact Labels** — tag and filter contacts for targeted sends.
- **Webhooks** — real-time delivery receipts, inbound messages, and channel health events. Meta and Telegram webhook payloads are verified server-side using HMAC-SHA256 before processing.

### Authentication

All API requests require the `X-MEGASEND-AUTH` header carrying a raw `secrets.token_urlsafe(32)` access token — **no** `Bearer` prefix, **no** token prefix string.

```bash
curl -X GET "https://api.megasend.co.il/instances/me" \
  -H "X-MEGASEND-AUTH: YOUR_ACCESS_TOKEN"
```
